# Foundation shell styling

The docs are a reading surface, not a marketing site. Their purpose is to explain the architecture, inspect token values, and try theme customization. The native app is a foundation inspection screen using platform controls.

These are provisional shell decisions, not a final brand identity: warm paper, dark ink, clay accent, semantic light/dark colors, and a locally bundled Newsreader face for web headings. System text remains the native default. The visual organization is a reference manual: persistent desktop contents, an overflow-safe mobile contents strip, readable sections, visible code, and token samples. Native settings use system switches, safe areas, a scalable text layout, and scrollable content.

No component catalog or reusable control styling has been established. Theme variables supply every web surface/text color; the shared theme supplies native colors. Future catalog work must define interaction and accessibility behavior before adding visual effects.
